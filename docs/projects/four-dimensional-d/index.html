Cell-State Differences Across Tissue Environments

NicheRadar maps functional niches. To study how those niches relate to the molecular state of a given cell type, we currently rely on researcher-guided ecotype analysis. This project aims to model that variation directly.

Research question

Can a model capture the context-dependent molecular differences that ecotype analysis helps us interpret, while distinguishing those differences from features characteristic of a cell type?

Approach

The focus is on cells of the same type across different tissue niches. Instead of using a separate ecotype analysis to interpret how their molecular profiles vary, the goal is to make that variation something the model can represent directly.

Project status

Work in progress. No results are reported here.
